Design System · Study · V1

Graphite Console

A monochrome, dark-only control-surface system, extracted from a five-screen UI study. Chrome only — no product content. The whole system runs on one grayscale ladder, one inverse accent, and one row height. Color is reserved entirely for the user's own content.

01 Principles
P1

Elevation is lightness, not shadow

Depth is a 5-step surface ladder. Each raised layer is one step lighter than its parent — no drop shadows on chrome. The only glow in the system belongs to interactive handles.

P2

White is the only accent

There is no hue anywhere in the chrome. The primary action inverts: white surface, near-black ink. Anything colored on screen is user content — which is exactly why the chrome stays gray.

P3

The control is the surface

Parameters are full-width rows you can grab anywhere: label left, value right, and the row itself is the slider track. No tiny thumbs, no separate tracks — a 48px target every time.

P4

Wayfinding by tracked caps

Sections are named with small uppercase labels (11px, +0.14em) and separated by hairlines — never by boxes or background changes. Structure whispers; controls speak.

P5

Numbers behave

Values are right-aligned, tabular-numeral, unit-suffixed (21°, 1.550, 600), and one ink step brighter than their labels. Scanning a column of values never zigzags.

P6

State = one step up the ladder

Selected and active means +1 surface step and brighter ink. Hover is a half-step. Disabled drops ink to faint but never changes the surface. One rule covers every component.

Segmented control

One pattern covers tabs, option pickers and on/off toggles — there are no switches in this system. Active segment steps up to bg-3 with ink-hi; container keeps 3px inner padding so nested radii stay concentric.

Four tiers of commitment. Primary is the inverse pair — the loudest thing chrome is allowed to be. Ghost for secondary, dashed for deferred/creative acts ("save as…"), text for escape hatches.

08 Motion

Motion is functional and brief — state changes, not theater. Two durations cover the system.

120msState flips — hover, active segment, check toggle
180msStructural — disclosure chevron, panel expand
ease-outcubic-bezier(.25,.1,.25,1) everywhere
0msScrubbing — value feedback is always immediate
09 Token sheet

Copy-paste starting point — the same variables this page is built from.

:root {
  /* surface ladder — elevation is lightness */
  --bg-0: #0f0f0f;  /* canvas */
  --bg-1: #171717;  /* panel / modal */
  --bg-2: #222222;  /* control at rest */
  --bg-3: #2e2e2e;  /* active / fill / selected */
  --bg-4: #3a3a3a;  /* hover on raised */
  --hairline: rgba(255,255,255,.08);

  /* ink ladder */
  --ink-hi: #f2f2f2;   --ink-mid: #b3b3b3;
  --ink-low: #8a8a8a;  --ink-faint: #5f5f5f;

  /* inverse pair — the only accent */
  --inverse-bg: #ffffff;  --inverse-ink: #101010;

  /* radius */
  --r-xs: 6px; --r-sm: 8px; --r-md: 12px;
  --r-lg: 16px; --r-xl: 20px; --r-pill: 999px;

  /* size & rhythm (base-4) */
  --row-h: 48px;        --gap-row: 10px;
  --pad-control: 16px;  --pad-panel: 20px;
  --gap-section: 32px;

  /* type: Geist for everything; hierarchy via size/weight/ink */
  --font-ui: "Geist", -apple-system, "Segoe UI", "Helvetica Neue", sans-serif;
  --font-mono: "Geist Mono", ui-monospace, monospace;
  /* display 56/700/-2% · title-lg 24/700 · title 19/650
     label 15/400 ink-mid · value 15/500 ink-hi tabular
     section 11/600/+14% CAPS · caption 13 · micro 12/500 */

  /* motion */
  --ease: cubic-bezier(.25,.1,.25,1);
  --t-fast: 120ms;  --t-med: 180ms;
}
